# Easy Offer Forge — AI 面试教练

基于 LLM 的模拟面试平台：围绕候选人的简历与个人知识库出题，实时追问、动态调难、多维评分，生成可追踪的进步报告。

把「练习 → 面试 → 复盘」做成闭环，而不是又一个题库刷题工具。

🌐 **在线体验**：[offerforge.joinuninook.com](https://offerforge.joinuninook.com)

---

## 为什么做这个项目

市面上的面试工具大多是题库 + 随机抽题，候选人刷完就忘。Easy Offer Forge 解决的核心问题是**个性化**和**闭环**：

- 题目来自你自己的简历和知识库，不是千篇一律的题库轮询
- 面试过程中 AI 会根据你的回答主动追问，而不是机械地切下一题
- 答完不是结束——四维评分 + 趋势报告告诉你哪里该补，下次练的时候难度自适应调整

## 核心能力

**面试引擎**
- 训练 / 实战双模式，五环节状态机驱动（开场 → 基础考察 → 项目经历 → 深度追问 → 收尾）
- 自适应难度：连续高分自动升级，答得吃力自动放缓，迟滞控制避免难度抖动
- 主动追问机制：基于回答内容生成针对性追问，追问次数有上限防止节奏拖垮
- 断点恢复：刷新或中断后可继续，会话状态带 TTL 自动清理

**资源库系统**
- 官方题库 318 题，覆盖五大方向 29 个分组 + LeetCode Hot 100 算法题，附解题思路与复杂度分析
- 支持上传个人面经笔记（仅本人可见），掌握度标记影响出题权重
- 面试时按分组选择资源，知识库内容注入 AI 上下文

**简历驱动**
- 多份简历管理，LLM 自动解析结构化
- 项目经历题由简历内容生成，面试围绕真实经验提问

**评估与追踪**
- 四维评分（准确性 / 完整性 / 清晰度 / 深度），锚点式约束减少 LLM 评分偏差
- 雷达图 + 趋势曲线，历史报告按训练 / 实战分页
- 短场保护：不足 5 题不扣额度、不记录历史

**账号与计费**
- 邮箱验证码注册，登录限流 + 会话管理
- 免费额度 + 余额计费，支持官方模型（通义千问 / DeepSeek 免费档）和自带 OpenAI 兼容 Key
- 管理台：用户统计 / 封禁、问题反馈处理

## 设计决策

### 状态机编排

面试是强流程场景，不能让 LLM 自由发挥。五环节状态机把流程收敛为确定性转移：每轮固定「评分 → 追问决策 → 难度调整 → 状态转移」四步编排，LLM 只负责单步评分与话术，转移条件全部是代码硬规则。难度调整用迟滞控制（连续 N 次高分才升档），避免单次抖动导致难度震荡。

### 三层 Memory

LLM 上下文有限，不能把整场面试原文塞进去。分三层处理：工作记忆（12 条滑动窗口对话原文）支撑追问引用；会话记忆（状态机快照 + TTL）承载环节 / 难度 / 连续分；长期记忆（MySQL）沉淀知识库 / 简历 / 报告。关键压缩策略——每题作答后立即被结构化评分记录替代原文，上下文长度恒定，20 轮面试不超窗。

### 评估系统

单分数没有诊断价值，拆成四维评分。提示词里给每维明确的锚点描述（什么样算 8 分、什么样算 4 分），要求输出严格 JSON。JSON 解析失败自动重试，仍失败降级保守评分保证流程不中断。报告层按环节聚合看趋势，不纠结单题分数。

### 多端点凭据路由

官方模型按 provider 字段路由到各自端点（通义千问 / DeepSeek 独立 base-url + api-key），用户自带 Key 优先于官方凭据，未配置时安全降级。用户 Key 用 AES-256-GCM 加密落库，baseUrl 强制 HTTPS 并拒绝内网地址防 SSRF。

## 快速开始

```bash
# 1. 拉起中间件
docker compose up -d mysql redis

# 2. 启动后端（默认 8081）
./mvnw spring-boot:run

# 3. 启动前端（默认 5173）
cd frontend && npm install && npm run dev
```

不配置 LLM Key 也能跑——AI 默认 mock provider，离线可完整走通全流程。接入真实模型时编辑 `.env` 即可。

完整部署（含 nginx / ES / 生产配置）：`docker compose -f docker-compose.prod.yml up -d --build`
