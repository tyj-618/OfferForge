# 功能引导

欢迎使用 Easy Offer Forge —— 基于 LLM 的 AI 面试教练。本文介绍各功能模块的使用方法，帮助你快速上手。

## 快速开始（三步上手）

1. **注册登录**：邮箱验证码注册（邮箱+验证码+用户名+密码），登录支持用户名或邮箱 + 密码；忘记密码可通过邮箱验证码重置。
2. **导入资料**：进入「资源库」，系统内置官方题库可直接使用；也可上传自己的笔记、面经，构建个人知识库。
3. **开始面试**：进入「模拟面试」，选择训练模式或实战模式开始一场完整面试；结束后自动生成多维评分报告。

## 模拟面试

模拟面试分为两种模式：

### 训练模式

- 面向练习与学习：每道题作答后，AI 导师会立即给出**人性化反馈**（答得好真诚表扬，答得不好鼓励引导）与**参考答案要点**，并给出评分。
- 支持**中断点恢复**：刷新页面或中途离开后，再次进入可从断点继续。
- 反馈气泡上提供「**🎯 深入该模块**」按钮：对某个模块想重点突破时，可一键跳转到该分组的专项训练，面试进度自动暂存，训练结束后回来续考。

### 实战模式

- 面向真实面试模拟：面试官按资深 Java 后端面试官人设提问，**不提前给反馈**，全程贴近真实面试节奏。
- 由浅入深自适应出题：连续高分会自动提升题目难度，答得吃力则保持基础难度循序渐进。
- 结束后统一生成评分报告，还原真实面试的完整体验。

### 面试通用说明

- 面试分为**基础考察、项目经历、深度追问、收尾总结**四个环节。
- 开始后先做自我介绍（可包含项目经历与熟悉的技术栈），随后正式进入提问环节。
- 未完成的面试会暂存 24 小时，下次进入「模拟面试」页可一键**继续未完成的面试**，也可以选择放弃重新开始。
- 内置 11 个预设岗位（Java 后端、Go 后端、前端、测试、运维、AI 应用等），也可自定义岗位方向，出题自动匹配对应知识分组。

## 专项训练

针对单一知识点分组的强化训练：

- 从资料库分组中选择一个方向（如 Java 并发、计算机网络等）开始训练。
- 由浅入深出题：连续高分自动升档难度，单场训练有固定题量上限。
- 每题作答后即时获得评分、导师反馈与参考答案要点。
- 支持刷新/暂离后恢复进度，也可主动提前结束并归档成绩。
- 训练成绩计入历史记录，可在报告中查看各分组的掌握情况。

## 快捷提问

- 有任何面试知识点疑问，直接提问即可。
- 系统会基于你的资料库检索相关知识点，生成结构化解答（先结论、后展开）。
- 适合查漏补缺：面试或训练中遇到没弄懂的概念，随手一问。

## 资源库

资源库是面试出题与问答的知识来源，分两类：

- **官方题库**：系统内置 300+ 道面试题，覆盖 Java 后端、前端、Go、测试/运维、AI 大模型五大方向 29 个分组，并含 **LeetCode Hot 100 算法题**（附解题思路与复杂度），开箱即用、所有人共享。
- **我的资料**：你自己上传的面经、笔记等文档（.md/.txt），仅本人可见，与官方资料互不干扰。

官方题库支持按题打勾/打叉标记掌握情况；上传后的资料会被切分、索引，参与出题与快捷提问的检索。资料越贴合你的目标岗位，面试与训练越有针对性。

## 简历

- 支持维护多份简历（如不同岗位方向各一份）。
- 开始面试时可选择一份简历作为背景，让项目经历环节的提问更贴合你的真实经历。

## 历史记录与报告

- 每场面试/训练结束后自动生成报告：总分、各维度评分、逐题得分与反馈、综合评价。
- 历史记录页展示所有场次，支持查看评分趋势图，直观看到自己的进步曲线。

## 设置与模型

- 在「设置」中管理个人 API Key（接入你自己的大模型服务）与账号相关配置。
- 未配置 API Key 时，系统使用官方模型（通义千问系列、DeepSeek 等）运行，享有每日免费额度。
- 充值功能正在审核中：顶栏「充值」页可查看余额、模型价目与充值档位，点击充值时暂不可用，审核通过后自动开放。

## 问题反馈

- 使用中遇到 Bug、有功能建议或其他意见，可在「文档 → 问题反馈」提交，支持图文描述。
- 反馈会直达运营团队，也可在同页查看自己提交过的历史反馈。

## 小贴士

- **先补资料，再开始面试**：资料库越完善，出题与追问越贴合你的知识体系。
- **善用「深入该模块」**：发现薄弱环节时立刻跳转专项训练，趁热打铁。
- **定期看趋势图**：分数波动很正常，关注长期趋势更有参考价值。
