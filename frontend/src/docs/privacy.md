# 隐私与安全

Easy Offer Forge 重视每一位用户的数据安全。本文说明我们收集哪些数据、如何保护它们，以及你可以行使的权利。

## 我们收集的数据

| 数据 | 用途 | 说明 |
| --- | --- | --- |
| 用户名 / 邮箱 / 密码 | 账号登录与找回 | 邮箱与账号一一对应，用于验证码注册与密码重置 |
| 简历内容 | 定制面试项目提问 | 仅本人可见，可编辑、可删除 |
| 上传的资料 | 个人知识库出题与问答 | 仅本人可见，与官方题库和其他用户完全隔离 |
| 面试/训练记录与作答 | 生成评分报告与趋势 | 仅本人可见 |
| 问题反馈内容 | 产品改进与问题处理 | 仅运营团队（管理员）可见 |

## 敏感信息保护措施

### 密码安全

- 密码使用 **BCrypt 加盐哈希**存储，系统不保存任何明文密码，即使数据库泄露也无法还原原密码。
- 登录接口带限流保护，防止暴力撞库；账号被封禁后登录与会话续期即时拦截。

### API Key 加密存储

- 你在「设置」中配置的自带 API Key，使用 **AES-256-GCM** 加密后存储，密文与密钥分离管理。
- Key 仅在你本人发起模型调用时使用，不出现在日志中，管理端也无法查看明文。

### 会话与访问控制

- 登录后签发短期访问令牌 + HttpOnly 刷新 Cookie，令牌过期自动续期，登出即失效。
- 所有个人数据接口严格按登录态鉴权：**简历、资料、记录、报告仅本人可访问**，跨用户访问一律拒绝且不泄露资源是否存在。

### 传输与基础设施

- 生产环境全站 HTTPS 加密传输。
- 数据库、缓存等中间件仅内网可访问，不对公网开放。
- 第三方模型调用仅传输当次出题/评分所需的内容；官方模型的调用凭据由平台托管，不向任何第三方共享你的账号信息。

## 数据使用边界

- 你的作答内容仅用于**当场的出题、评分与报告生成**，不用于向其他用户展示，不用于广告等无关用途。
- 官方题库为平台公开内容；你上传的私有资料绝不进入官方题库，也不会被其他用户检索到。

## 你的权利

- **删除权**：可随时删除自己的简历、上传资料、反馈等个人数据。
- **更正权**：可随时修改简历与个人配置；密码可通过邮箱验证码重置。
- **反馈与申诉**：任何隐私相关疑问或数据诉求，可通过「问题反馈」提交，我们会跟进处理。
