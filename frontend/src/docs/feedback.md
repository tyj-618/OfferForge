# 问题反馈

你的反馈是产品改进最重要的输入。遇到 Bug、有新功能想法、或任何其他意见，都可以在本页直接提交。

## 如何提交

1. 选择反馈类型：**问题缺陷**（功能报错、行为异常）、**功能建议**（希望新增或改进的功能）或**其他**。
2. 填写问题描述：尽量写清操作步骤与预期/实际表现，建议类可描述使用场景。
3. 可选上传截图：最多 3 张、单张不超过 1MB，图文提交能让问题定位更快。
4. 点击「提交反馈」。

## 提交后会发生什么

- 反馈会实时同步到运营团队的管理台，由管理员查看与跟进。
- 你可以在本页下方「我的反馈」中查看自己提交过的历史记录。
- 为防止滥用，每个账号每日最多提交 20 条反馈。

## 注意事项

- 请勿在反馈内容中粘贴密码、API Key 等敏感信息。
- 涉及账号安全的问题（如无法登录），请提供注册邮箱以便核实（无需提供密码）。
