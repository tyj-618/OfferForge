# 更新日志

记录 Easy Offer Forge 各版本的功能变化。

## v1.0（当前版本）

v1.0 是产品首个正式版本，覆盖「学、练、测、评」完整闭环：

### 账号与登录

- 邮箱验证码注册：邮箱 + 验证码 + 用户名 + 密码，账号与邮箱一一对应
- 登录支持「用户名 + 密码」或「邮箱 + 密码」双入口
- 忘记密码：邮箱验证码验证后直接重置密码
- 唯一管理账号体系与管理台（用户统计、检索、封禁/解封、问题反馈查看）

### 核心功能

- **模拟面试**：训练/实战双模式，四环节状态机流程（基础考察 → 项目经历 → 深度追问 → 收尾总结），由浅入深自适应出题、主动追问、断点恢复、训练模式「深入该模块」跳转专项训练
- **专项训练**：按知识分组强化训练，即时评分与导师反馈，刷新/暂离恢复，训练报告与打印
- **快捷提问**：基于个人知识库检索的结构化问答（先结论、后展开，带引用）
- **资源库**：官方题库 300+ 题（29 分组 + LeetCode Hot 100 算法题），支持上传个人面经笔记（仅本人可见）、分组管理、掌握度标记
- **简历**：多份简历维护、预览/编辑分离，面试按简历定制项目提问
- **历史记录与报告**：按模式分页记录、评分趋势图、多维报告（维度评分、逐题明细、综合评价）

### 模型与计费

- 官方模型：通义千问系列（qwen-flash 免费档）+ DeepSeek（deepseek-v4-flash），支持用户自带任意 OpenAI 兼容 API Key
- 免费额度：无自带 Key 用户每日免费额度，超限引导配置 Key
- 付费计费：充值档位、模型价目、余额计费接口已就绪；**支付渠道审核中，入口展示但暂不开放操作**

### 问题反馈

- 「文档 → 问题反馈」支持图文提交，管理台可查看处理

### 安全与隐私

- API Key AES-256-GCM 加密存储、密码 BCrypt 加盐哈希、登录限流与会话管理
- 详见「隐私与安全」文档
